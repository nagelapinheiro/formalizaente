# Evidências de execução

Esta pasta é preenchida durante a execução da V4.

- `python -m src.pipeline` gera `ingestao.json`;
- `python -m src.answer` gera `resultado_completo.csv`.

As evidências não são pré-fabricadas para evitar divergência entre o repositório e a execução
apresentada. Antes da apresentação, execute o fluxo completo e versione as evidências se a equipe
quiser manter um plano de contingência.
